I N S T A L L I N G   T H E   J V M

If you do not currently have Internet Explorer 4.0 or the IE 4.0 Java Virtual
Machine (JVM) installed, you will need to do so to run the Millennium Clock.

The easiest way to do this is to download and install Internet Explorer 4.0,
which has the required JVM built in: 

- Point your browser to http://www.microsoft.com/ie/
- Download the IE 4.0 Installer.
- Launch the installer and follow the instructions on your screen to install
IE 4.0.

If you do not wish to use the IE 4.0 browser, you will still need to install
the IE 4.0 Java Virtual Machine:

- Point your browser to http://www.microsoft.com/java/vm/dl_vmsp2.htm
- Download the IE 4.0 JVM Installer.
- Launch the installer and follow the instructions on your screen to install
the IE 4.0 JVM.



I N S T A L L I N G   T H E   C L O C K

The Millennium Clock is shipped as a self-extracting executable containing all
the necessary program and support files. To install the clock:

- Double-click the RSI_CLOCK.EXE icon.
- In the installer dialog box, enter the path to the folder into which you
would like to install the clock. (By default, the clock will be installed into
the 'Program Files' folder.)
- Click 'Unzip' to perform the installation.

Please note that the Millennium Clock does not install any hidden files. To
remove this program from your system, just drag the entire 'Millennium
Clock' folder to the Recycle Bin.



R U N N I N G   T H E   C L O C K

When you start the Millennium Clock, it will attempt to query a Network Time
Protocol (NTP) server to obtain an accurate time signal. If there is no network
connection, it will use your Windows system clock and periodically check to
see if a connection has been established.

To ensure accurate time, it is therefore recommended that you establish a
network connection before running the Clock.

C l o c k   M o d e   B u t t o n
The Clock Mode Button (above and to the left of the time readout) lets you
cycle through the Clock's three modes: Time, Date, and Millennium Countdown.
(Please note that we are referring to the 'popular' definition of the
Millennium, i.e. midnight, December 31, 1999.)

E a r t h   A n i m a t i o n
This is an accurate depiction of the planet's position based on your computer's
timezone settings. The area near the center of the visual field is the area for
which it is currently 3:00 pm. For example, if you are in the Pacific Standard
Timezone (PST) and it is currently 3:00 pm, you should be seeing the West Coast
of the U.S. near the center of the visual field, moving slowly towards the
terminator as the day progresses.

You can also click and drag the Earth to move forward or backward in time!
